Застосунок Mova

  • Mova просить у macOS два дозволи. Input Monitoring — бачити натиснуті клавіші, щоб розпізнати слово, набране не в тій розкладці. Accessibility — стерти це слово й надрукувати його в іншій розкладці. Mova використовує ці дозволи лише для цього.
  • Набраний текст нікуди не надсилається і не зберігається: у пам’яті лише поточне й останнє слово. У полях паролів Mova не бачить клавіш.
  • Раз на добу Mova перевіряє оновлення на GitHub і підтверджує ліцензію на нашому сервері. Для ліцензії передаються ключ, псевдонімізований ідентифікатор Mac (хеш апаратного ідентифікатора, з якого не можна відновити сам ідентифікатор чи серійний номер) і версія Mova. Цей хеш пов’язаний з вашим ключем, тому ми вважаємо його персональними даними.
  • Аналітики, реклами й облікових записів немає. Власних звітів про збої Mova не надсилає; якщо в macOS увімкнено надсилання аналітики Apple, такі звіти обробляє Apple.
